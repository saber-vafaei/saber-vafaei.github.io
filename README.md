# Saber Vafaei — Professional Portfolio Website

A responsive, one-page professional portfolio built with plain HTML and CSS for GitHub Pages.

## Files
- `index.html` — website content and navigation
- `styles.css` — responsive visual design
- `assets/saber-site-photo.png` — supplied site photograph
- `assets/Saber-Vafaei-CV.pdf` — supplied CV, linked from the hero section

## Publish with GitHub Pages
1. Sign in to GitHub and create a **new public repository**. A suitable name is `saber-vafaei-portfolio`.
2. Upload the contents of this folder (upload `index.html`, `styles.css`, `README.md`, and the `assets` folder — not the outer folder itself).
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. Wait for GitHub Pages to publish. The site address will normally be:
   `https://YOUR-GITHUB-USERNAME.github.io/saber-vafaei-portfolio/`

## Before publishing
- Confirm that the phone number, email address, LinkedIn URL and CV are intended for public display.
- Consider replacing the current site photo with a higher-resolution, landscape or portrait professional site photograph if available.
- The website content is based on the supplied CV. No project values, budgets, team sizes, Australian work rights, tickets or licences have been added.
- The supplied CV describes English as “Developing professional proficiency”; this wording has been retained rather than overstating fluency.
- The page uses Google Fonts when available and falls back to system fonts if they are blocked.

## Recommended next improvements
For a stronger Australian-market portfolio, add verified project case studies with project scope, personal responsibilities, construction methods, deliverables and measurable outcomes. Only publish figures and claims that can be substantiated.
