# سایت شخصی صابر وفایی — نسخه جدید

این بسته برای انتشار مستقیم در GitHub Pages آماده شده و به سیستم مدیریت محتوا، نصب پکیج یا سرور نیاز ندارد.

## پیش‌نمایش

فایل `index.html` را در مرورگر باز کنید. برای عملکرد کامل دکمه Copy و فایل‌های خارجی، بهتر است سایت را روی GitHub Pages ببینید.

## جایگزینی سایت فعلی

آدرس پروژه GitHub شما:

https://github.com/sabervafaeice-cyber/saber-vafaei

1. از پوشه `saber-vafaei-website` فایل‌های `index.html`، `style.css`، `script.js`، `Saber_Vafaei_CV.pdf` و پوشه `assets` را بردارید.
2. آنها را **داخل ریشه مخزن** `saber-vafaei` قرار دهید، نه داخل یک پوشه اضافی. فایل `index.html` قبلی باید جایگزین شود.
3. تغییرات را commit کنید و از فعال بودن GitHub Pages در **Settings → Pages** برای شاخه مورد نظر (معمولاً `main`، پوشه `/root`) اطمینان حاصل کنید.
4. آدرس سایت: https://sabervafaeice-cyber.github.io/saber-vafaei/

برای کار با Git در رایانه:

```bash
git clone https://github.com/sabervafaeice-cyber/saber-vafaei.git
cd saber-vafaei
# فایل‌های این بسته را در همین پوشه کپی کنید و index.html قدیمی را جایگزین کنید.
git add -A
git commit -m "Redesign personal site with real field photos"
git push origin main
```

اگر شاخه اصلی نام دیگری دارد، در فرمان push نام همان شاخه را استفاده کنید.

## ویرایش متن و عکس

- همه متن‌ها در `index.html` هستند و می‌توانید مستقیم تغییر دهید.
- عکس‌ها در `assets` هستند؛ چهار عکس واقعی که ارسال کردید با تبدیل به WebP سبک‌تر شده‌اند.
- رنگ‌ها و ظاهر سایت در `style.css` هستند.
- اطلاعات تماس، موقعیت حرفه‌ای، سابقه و مدارک بر اساس CV پیوست‌شده تنظیم شده‌اند.
- برای نمایش عکس‌های بیشتر، عکس‌های واقعی از مراحل بتن‌ریزی، قالب‌بندی، آرماتور، فونداسیون، آزمایشگاه یا نقشه‌های بدون اطلاعات محرمانه اضافه کنید. برای عکس‌هایی که اجازه انتشار آنها را ندارید از آنها استفاده نکنید.
- از درج مقادیر ساختگی مثل تعداد پروژه‌ها، حوادث صفر یا درصد صرفه‌جویی خودداری شده است.

**نکته:** تنها ۴ عکس واقعی در اختیار داشتیم؛ باقی بخش‌های سایت با طراحی گرافیکی اصلی، تایپوگرافی، یادداشت‌های دست‌نویس و چیدمان متنوع کامل شده‌اند. هیچ تصویر استوک به عنوان عکس شخصی جا زده نشده است.
